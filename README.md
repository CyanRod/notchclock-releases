# NotchClock para Windows

[Descargar la última versión](https://github.com/CyanRod/notchclock-releases/releases/latest)

Este repositorio distribuye únicamente instaladores y metadatos de actualización. El repositorio de desarrollo no se publica aquí.

## Instalar o actualizar

Descarga el archivo NotchClock-Setup-<versión>.exe del release. Si usas 1.4.27 o anterior, instala una vez 1.4.28 o posterior. Después podrás abrir Ajustes → General → Actualizaciones para buscar, descargar y reiniciar cuando lo decidas.

El instalador Windows todavía no está firmado con certificado; puede aparecer una advertencia de editor desconocido. Descarga solo desde los releases de este repositorio.

Los archivos latest.yml y .blockmap son para el actualizador; no necesitas abrirlos.
